# ☑️ TaskFlow — локальный трекер рабочих задач

Одностраничное приложение для управления рабочими задачами. Работает полностью локально, без интернета и без сервера: все данные хранятся в `localStorage` вашего браузера.

## Быстрый старт

1. Откройте `index.html` в браузере (двойной клик, или перетащите файл в окно браузера). Рекомендуются свежие версии Chrome или Edge.
2. Всё готово — при первом запуске загружаются демо-данные, чтобы показать возможности.

> Сервер не нужен: файлы хранятся во встроенной библиотеке (IndexedDB) и открываются без `python -m http.server`.

## Возможности

- **Задачи**: название, описание, статус («К выполнению» / «В работе» / «Выполнено»), приоритет P1–P3, срок, теги, подзадачи с прогресс-баром.
- **Папки**: древовидная структура проектов с подпапками, цветами и сворачиванием. Вложенность не ограничена. Счётчики открытых задач.
- **🗂 Библиотека файлов** — встроенное хранилище (IndexedDB), работает **без сервера**:
  - загрузка файлов с диска, папки файлов со вложенностью;
  - к задаче файл прикрепляется кнопкой «📎 Файл с диска» (файл сразу сохраняется в библиотеку) или «🗂 Из библиотеки» (выбор из уже загруженных);
  - **активные гиперссылки**: файлы открываются по клику, внешние URL/пути — кликабельные чипы в списке задач и кнопки ↗ в окне задачи; файл можно прикрепить к нескольким задачам;
  - **открытие в родных приложениях Windows**: файлы с диска открываются в Word/Excel и других приложениях, папки — в Проводнике (см. «Интеграция Windows» ниже).
  - внешние ресурсы добавляются обычной ссылкой (URL или путь).
- **👥 Команда и ответственные**: справочник команд и сотрудников (👥 Команда), назначение команды и ответственного на задачу, фильтры и сортировка по ним, отражение в отчётах.
- **Отчёты** (`📊 Отчёты`):
  - *Сводка* — статистика, просроченные, выполненные за 7 дней, разбивка по папкам, командам и ответственным;
  - *Текстовый отчёт* — краткое описание всех задач / в работе / выполненных; можно скопировать, скачать в **.md** или **.html**, распечатать;
  - **фильтр «Отчёт по…»** — по конкретной команде или сотруднику: сводка, списки и раскладка по сотрудникам команды;
  - *AI-отчёт* — выбор области: все / открытые / выполненные / просроченные / из проекта / вручную галочками; DeepSeek готовит итоги, приоритеты, риски и рекомендации (скачивание в .md и .html).
- **📝 Журнал и заметки**: хранение заметок, протоколов и листингов совещаний с тегами и поиском. AI DeepSeek: **✨ Резюме** (подробное резюме записи), **📋 Протокол** (структурированный протокол совещания), **🎯 В задачи** (передача текста в разбор «текст → задачи»).
- **📚 База знаний**: статьи с тегами и **мгновенным поиском** по названию, содержимому и тегам (с подсветкой совпадений); AI **✨ Структурировать** оформляет статью.
- **AI DeepSeek** (`✨ AI DeepSeek`):
  - суммаризация описания задачи;
  - разбиение задачи на подзадачи;
  - **разбор произвольного текста** (письмо, протокол встречи) в список задач с приоритетами и сроками.
- **Поиск, фильтры, гибкая сортировка**: поиск по названию/описанию/тегам/ответственному (`/`); фильтры по статусу, приоритету, команде и ответственному; сортировка по приоритету / сроку / дате создания / дате обновления / названию / проекту / ответственному / команде / статусу + переключатель направления ⬇️⬆️.
- **Экспорт/импорт**: единый JSON-бэкап задач, папок, справочников, **заметок, статей базы знаний и файлов библиотеки** (перенос на другой компьютер без потерь). Импорт объединяет данные.
- **Обновления без потерь**: при загрузке данные предыдущих версий автоматически мигрируются; старая версия сохраняется в `localStorage` под ключом `taskflow.backup.v*`.
- **Тёмная/светлая тема**, горячие клавиши: `N` — новая задача, `/` — поиск, `Esc` — закрыть окно.

## Настройка AI DeepSeek

1. Получите API-ключ на [platform.deepseek.com](https://platform.deepseek.com) → «API Keys».
2. В приложении откройте `✨ AI DeepSeek` → вкладка **Настройки**, вставьте ключ и нажмите «Проверить подключение».
3. Ключ хранится **только** в вашем браузере (`localStorage`) и отправляется исключительно в API DeepSeek.

Поддерживаемые модели: `deepseek-chat` (быстрая) и `deepseek-reasoner` (глубокая, медленнее). Базовый URL можно заменить (например, на прокси).

> Если при обращении к API возникает ошибка сети: используйте свежий Chrome/Edge (на `file://` запросы работают), либо откройте приложение через локальный сервер (`python -m http.server 8000` → `http://localhost:8000`). Кнопка «Проверить подключение» покажет точную причину.

## Интеграция Windows (открытие файлов в родных приложениях)

Браузер сам не умеет запускать Word/Excel и Проводник. TaskFlow решает это через протоколы `taskflow-open:` (файлы) и `taskflow-folder:` (папки):

1. Откройте в приложении **⚙️ Система**.
2. Скачайте **Установить_интеграцию.bat** и запустите его двойным кликом (прав администратора не нужно, устанавливается в HKCU).
3. Нажмите «Проверить» — должно появиться окно «Интеграция работает». Если нет — перезапустите браузер.
4. После этого ссылки с путём к файлу открываются в соответствующем приложении, ссылки на папки — в Проводнике. Тумблер в ⚙️ Система позволяет вернуть обычный режим.

> Файлы, загруженные во встроенную библиотеку, хранятся в браузере (без реального пути на диске), поэтому открываются во встроенном просмотрщике (PDF, изображения, текст). Для открытия в Word/Excel добавьте их как ссылку с путём на диске.

## Структура проекта

```
ToDo_tracker/
├── index.html   — разметка приложения
├── styles.css   — стили (тёмная/светлая тема)
├── app.js       — данные (localStorage), папки, задачи, команды, журнал, база знаний, отчёты, экспорт
├── storage.js   — библиотека файлов (IndexedDB)
├── files.js     — интерфейс библиотеки файлов
├── ai.js        — интеграция с DeepSeek API
└── README.md
```

## Заметки

- Данные задач хранятся в `localStorage`, файлы библиотеки — в IndexedDB, оба хранилища привязаны к браузеру и профилю. Перед сменой браузера/компьютера сделайте «Экспорт JSON» (включает файлы) и импортируйте на новом месте.
- «Сегодня» включает просроченные задачи, чтобы ничего не потерялось.
- При удалении папки её задачи переносятся во «Входящие», при удалении папки файлов — файлы переносятся в корень библиотеки.
- Обновление трекера (замена файлов `index.html`, `*.css`, `*.js`) не затрагивает данные: они хранятся в браузере, а при изменении формата выполняется автоматическая миграция с резервной копией старой версии.
