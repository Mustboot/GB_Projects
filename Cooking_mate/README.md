# Cooking_mate — файлы себестоимости десертов

## Состав папки

| Файл | Назначение |
|---|---|
| `Ингредиенты.xlsx` | **Единый каталог всех ингредиентов** (упаковка, цена). Один источник цен для всех остальных файлов. |
| `Бисквитные торты - себестоимость.xlsx` | 6 тортов, на каждой вкладке расчёт для **D16 / D18 / D20** |
| `Многослойные торты - себестоимость.xlsx` | 7 тортов, на каждой вкладке расчёт для **D16 / D18 / D20** |
| `Моти - себестоимость.xlsx` | 4 вида моти |
| `Тарты - себестоимость.xlsx` | 3 тарта + вкладка `Исходник` (шаблон для нового тарта) |
| `rebuild_workbooks.py` | Скрипт, которым пересобраны файлы (при необходимости — повторный запуск) |
| `_backup_original/` | Резервная копия исходных файлов **до** пересборки |

## Главное правило

**Все 5 xlsx-файлов должны лежать в одной папке** (например, в одной папке OneDrive).
Не переименовывайте `Ингредиенты.xlsx` — на него ссылаются формулы всех рецептов.

## Как менять цены / упаковки

1. Откройте `Ингредиенты.xlsx` и поправьте нужные строки.
2. В файлах рецептов значения обновятся автоматически:
   - на компьютере Excel предложит **«Обновить связи» → Обновить**;
   - на телефоне (Excel для Android) — обновится само.
3. Новый продукт, добавленный в каталог, сразу появляется в выпадающем
   списке ячеек «Ингредиент» во всех рецептах.

## Расчёт на вкладке рецепта

- Колонки `D16 / D18 / D20` — количество (г/мл/шт) для каждого диаметра.
  Прежние граммовки приняты за **D18**; D16 и D20 пересчитаны по площади
  круга (×0,79 и ×1,23). При желании поправьте вручную.
- Блок **ИТОГИ** (справа сверху): вес, себестоимость, цена за 1 кг,
  расчёт под желаемый вес и себестоимость 1 шт.
- **Жёлтые** ячейки — то, что нужно заполнять/менять.
- Если ввести ингредиент, которого нет в каталоге, строка подсветится
  **красным** — добавьте продукт в `Ингредиенты.xlsx`.

## Телефон

Формат оптимизирован для Samsung Galaxy S22+:
- таблица компактная, шапка и колонки «Раздел»/«Ингредиент» закреплены;
- выбор ингредиента — выпадающим списком;
- редактируются только жёлтые ячейки (имена, количества, желаемый вес).

**Внимание:** связи между файлами поддерживает Microsoft Excel
(компьютер и Android). Google Sheets / Яндекс.Документы связи между
файлами не читают — в них открывать файлы рецептов не рекомендуется.

## Если связи «отвалились»

- Файлы разложены по разным папкам → верните их в одну папку.
- Файл каталога переименован → верните имя `Ингредиенты.xlsx`.
- Иначе: в Excel **Данные → Изменить связи → Изменить источник** и
  укажите `Ингредиенты.xlsx`.
