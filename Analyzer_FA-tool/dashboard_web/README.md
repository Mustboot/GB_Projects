# DrillingLogs Dashboard — веб-дашборд параметров бурения

Интерактивный HTML-дашборд профессионального уровня: кривые бурения и каротажа
по глубине из базы `DrillingLogs_full.accdb`, размещённые треками друг под другом
и синхронизированные по глубине.

## Возможности

- **Четыре основных равновеликих плота**, строго одного размера и
  синхронизированных по глубине (масштаб/сдвиг/видимость скважин зеркалируются;
  отступы у всех плотов одинаковые, поэтому области построения совпадают по
  ширине; высота ≥ 280 px, при нехватке места карточка прокручивается):
  - **ECD** (ppg); **БУРЕНИЕ** — ROP · RPM · TFLO (три оси Y); **GR** (gAPI);
  - **КАВЕРНОМЕТРИЯ** (UCAV/DCAV, дюйм).
- **Секция «Геология»** — для каждой выбранной скважины с RHOB своя компактная
  пара плотов (не высокие):
  - **ЛИТОЛОГИЯ · <скважина>** — заливка фона на весь плот по классам плотности:
    🟨 песчаник < 2.2, 🟧 алевролит 2.2–2.5, ⬜ аргиллит ≥ 2.5 г/см³;
  - **ПЛОТНОСТЬ · <скважина>** — линия RHOB, раскрашенная по тем же классам.
  - Оба плота синхронизированы по глубине с остальными; при выключении
    скважины в легенде её пара скрывается целиком.
- **Синхронизация по глубине**: общий масштаб по X между всеми плотами,
  единый курсор (crosshair), объединённая подсказка, слайдер-диапазон глубин
  под нижним плотом; отключение скважины в легенде скрывает её на всех плотах.
- **Выбор данных**: мультивыбор скважин (с поиском), переключатели кривых,
  интервал глубин; у каждой скважины свой различимый цвет (палитра
  для дальтоников), легенда интерактивна (клик — скрыть/показать скважину).
- **Отчёт на печать / PDF** — кнопка «Печать / PDF» (рекомендуется альбомная
  ориентация).
- **Экспорт в Excel (.xlsx)** — лист «Сводка» + отдельный лист на каждую
  скважину (столбцы «Глубина» и выбранные кривые, шапки и фильтры настроены).
  Данные прореживаются методом min/max (пики сохраняются).
- **Работает офлайн** — Plotly.js входит в комплект (`static/plotly.min.js`).

## Запуск

Двойной клик по `start_dashboard.bat`
(или в консоли: `python dashboard_web\server.py`).

Браузер откроется автоматически: <http://127.0.0.1:8000/>

Параметры сервера:

```
python dashboard_web\server.py --port 8000 --host 127.0.0.1 --db DrillingLogs_full.accdb --no-browser
```

## Требования (Windows)

- Python 3.10+ с пакетами: `pyodbc`, `openpyxl`
  (в рабочем окружении проекта они уже установлены);
- Драйвер **Microsoft Access ODBC Driver (\*.mdb, \*.accdb)** —
  обычно входит в состав Microsoft 365 / Access Database Engine.

## API (для разработчиков)

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/meta` | скважины, кривые, диапазоны, доступность данных |
| GET | `/api/data?wells=1,2&curves=ROP,ECD&dmin=0&dmax=5000&points=1500` | данные кривых (min/max-прореживание) |
| POST | `/api/export` | `.xlsx`-отчёт по текущему выбору (JSON: wells, curves, dmin, dmax) |
